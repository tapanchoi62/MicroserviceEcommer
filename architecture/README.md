# Ecommerce Microservice Architecture

Enterprise-grade ecommerce platform using microservice architecture.

## Technology Stack

### Frontend

- NextJS
- React
- TailwindCSS

### Backend

- NestJS
- PostgreSQL
- Redis
- Kafka
- Elasticsearch

### Infrastructure

- Docker
- Kubernetes
- GitHub Actions
- Prometheus
- Grafana

## Core Services

- Auth Service
- User Service
- Product Service
- Cart Service
- Order Service
- Inventory Service
- Payment Service
- Shipping Service
- Search Service
- Notification Service

## Architecture Patterns

- Domain Driven Design (DDD)
- Event Driven Architecture
- Saga Pattern
- Outbox Pattern
- CQRS
- API Gateway

## Deployment

- Kubernetes Cluster
- CI/CD Pipeline
- Docker Registry
- Monitoring Stack
