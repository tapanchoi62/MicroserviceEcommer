# Cart Service

## Responsibilities

- Shopping Cart
- Guest Cart
- Cart Merge
- Realtime Cart

## Storage

Redis-based storage.

## APIs

```http
POST   /cart/items
GET    /cart
PUT    /cart/items/:id
DELETE /cart/items/:id
```

## Features

- High-speed access
- Cart expiration
- Coupon preview
- Realtime updates
